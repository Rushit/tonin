# Code of Conduct

## Our pledge

We — contributors and maintainers — pledge to make participation in the tonin community a harassment-free experience for everyone, regardless of age, body size, visible or invisible disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, religion, or sexual identity and orientation.

## Standards

Behaviors that build community:

- Using welcoming and inclusive language
- Respecting differing viewpoints and experiences
- Accepting constructive criticism gracefully
- Focusing on what's best for the project and its users
- Showing empathy toward other community members

Behaviors that do not:

- Sexualized language or imagery, and unwelcome sexual attention or advances
- Trolling, insulting / derogatory comments, personal or political attacks
- Public or private harassment
- Publishing others' private information (physical or electronic address) without explicit permission
- Conduct which could reasonably be considered inappropriate in a professional setting

## Scope

This Code of Conduct applies in all project spaces — the GitHub repository (issues, PRs, discussions, code comments), any official communication channel, and when representing the project in public.

## Enforcement

Report unacceptable behavior by opening a GitHub issue tagged `[conduct]` on https://github.com/Rushit/tonin/issues. Include only enough detail to identify the incident; a maintainer will reach out privately to follow up.

Project maintainers are obligated to respect the privacy and security of the reporter of any incident. Maintainers who do not follow or enforce the Code of Conduct in good faith may face temporary or permanent repercussions as determined by other project maintainers.
